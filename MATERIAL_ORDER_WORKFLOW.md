# Material order approval workflow

## Employee

1. Log in and open **Employee Portal**.
2. Open **Generate Forms** and select the job.
3. Select **Start Material Order**.
4. Enter the required delivery date, preferred supplier and site notes.
5. Add saved products or one-off materials to the draft.
6. Review or remove draft lines.
7. Select **Submit Material Order to Admin**.
8. Check the order history for status and admin comments.
9. If returned, edit the same order and submit it again.
10. Once approved, download the approved PDF from the order history.

Employee accounts do not see product pricing.

## Admin

1. Open **Materials**.
2. Review **Material Order Approval Queue**.
3. Select an order awaiting approval.
4. Check job, delivery date, supplier, quantities, colours, notes and estimated value.
5. Add admin comments and choose:
   - **Approve and Generate PDF**
   - **Return for Changes**
   - **Reject Request**

Approval creates the final PDF, attaches it to the job documents, and posts the approved items to
the job material cost register. The same order cannot post its items twice.
